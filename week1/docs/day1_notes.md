## What is kyber?
- KEM = Key Encapsulation Mechanism
- NIST standard: FIPS 203
- 3 variants: Kyber-512, 768, 1024

## Kyber-512 (Best for Iot)
- Public key: 800 B
- Private key: 1632 B
- Ciphertext: 768 B
- Shared secret: 32 B
